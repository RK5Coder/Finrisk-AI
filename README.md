# FinRisk AI - Fraud Detection Dashboard

A professional fraud detection system with 99.53% accuracy using machine learning.

## Features

- Real-time fraud detection with 99.53% accuracy
- Professional dashboard with 5 pages
- Risk analysis and alert system
- Business recommendations and insights
- Clean, responsive interface

## Technology Stack

- Python 3.9+
- Streamlit for dashboard
- Pandas for data processing
- Plotly for visualizations
- Scikit-learn for machine learning

## Installation

1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the dashboard: `streamlit run app.py`

## Project Structure
```
finrisk-ai/
```
